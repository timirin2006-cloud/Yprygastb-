# Сила упругости — физика, 9 класс

Интерактивный учебный сайт для онлайн-урока.

## Как открыть
1. Откройте `index.html` в браузере.
2. Для GitHub Pages загрузите `index.html` в репозиторий и включите Pages в настройках репозитория.

## Что внутри
- определения деформации, упругой и пластической деформации;
- закон Гука, обозначения и единицы измерения;
- бытовые примеры;
- интерактивная модель пружины с ползунками;
- тест из 5 вопросов с автоматической проверкой;
- задачи от лёгкой до сложной с раскрывающимися решениями.

## Примечание
Сайт — учебный конспект по школьной теме «Сила упругости. Закон Гука». Практические задачи составлены для урока и не выдаются за дословные упражнения из учебника.
